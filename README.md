# Quantum Market VQE Signals

Experimental quantum-inspired market model using Qiskit VQE.

## Features

- Variational Quantum Eigensolver (VQE)
- Volatility-weighted Hamiltonian
- Probabilistic Buy / Hold / Sell signals
- Google Colab compatible

## Files

- `Quantum_Market_VQE_Signals.ipynb` → Interactive notebook
- `quantum_market_vqe_signals.py` → Standalone Python script

## Requirements

- Python 3.10+
- Qiskit
- yfinance
- numpy
- matplotlib
